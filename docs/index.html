為車廠服務團隊打造的排班與請假管理工具。櫃檯、技師與現場接待，一張週班表掌握出勤與人力缺額。

本機執行 · SQLite 儲存 · 無需雲端資料庫

工具功能

從排班到請假，讓安排更清楚。

自動排班

依職務需求、每週出勤上限與請假安排班表，平衡同職務的工作量；也可手動調班。

請假與缺額管理

登記請假後移除衝突班次，顯示每日各職務的人力缺額，方便重新安排。

CSV 匯出與本機保存

匯出週班表供團隊使用。資料保存在本機 SQLite，停止服務後複製資料庫即可備份。

一起把工具變成你的工作方式

有不同的流程？歡迎找我開發。

客製化排班

依團隊的職務、班別與營運需求討論規則，讓工具配合現場流程。

公司內部部署

評估公司環境，規劃登入權限、資料備份與內網使用方式，協助導入日常工作。

更多系統開發

不只排班。若有表單、簽核、報表或重複性工作，歡迎一起討論適合的系統。

上述為可洽談的開發服務；目前工具為本機單一工作區版本，尚未包含登入、權限分級及多人內網部署。

常見問題

需要安裝什麼才能使用？

需要 Python 3.9 以上與標準函式庫 SQLite。下載專案後使用啟動檔，在本機瀏覽器開啟；不需安裝 npm 或額外 Python 套件。完整步驟請見 GitHub README。

可以直接讓全公司連線嗎？

目前版本僅供本機使用，沒有登入與權限分級。公司內部部署需要另行規劃存取控制、備份與運行環境，歡迎與我討論。

其他產業也能客製化嗎？

歡迎提供你的班別、角色與作業流程，一起評估需要調整的功能與開發範圍。
